### #1 ポイントカードはお持ちですか？
```
## 听懂
原文：ポイントカードはお持(も)ちですか？
意思：请问您有积分卡吗？
要点：「お持(も)ちですか」是「持(も)っていますか」的敬语说法，店员对顾客的固定问法。

## 回复建议
1. 丁寧⭐｜いえ、【持(も)っていません】。
   → 不，我没有。
2. カジュアル｜ううん、【持(も)ってない】。
   → 不，没有。
3. かんたん｜いいえ、【ありません】。
   → 不，没有。
推荐理由：对方用了「お持(も)ちですか」这种敬语，且是店员，所以用丁寧最稳妥。若有卡可说「はい、【持(も)っています】」或「はい、これでお願(ねが)いします」。

## 生词
- ポイントカード：积分卡、会员卡
- お持(も)ちですか：「持(も)っていますか」的敬语，意为「您有……吗」
```

### #2 お箸おつけしますか？
```
## 听懂
原文：お箸(はし)おつけしますか？
意思：要给您放筷子吗？
要点：「おつけする」是「付(つ)ける」的谦让语（店员对客人的说法），意思是「附上、放进袋子里」。

## 回复建议
1. 丁寧⭐｜はい、お願(ねが)いします。
   → 好的，麻烦了。
2. カジュアル｜うん、箸(はし)ちょうだい。
   → 嗯，给我筷子。
3. かんたん｜はい、おねがいします。
   → 好的，麻烦了。
推荐理由：对方是店员，用了「おつけしますか」这种谦让语，所以用丁寧回答最稳妥。若想拒绝，可说「いえ、大丈夫(だいじょうぶ)です」，前面一定要加「いえ」，否则对方分不清你是要还是不要。

## 生词
- お付(つ)けする：（店员说）附上、给您放上
- 箸(はし)：筷子
```

### #4 少々お待ちいただけますか？
```

原文：少々(しょうしょう)お待(ま)ちいただけますか？
意思：能请您稍等一下吗？
要点：「お待(ま)ちいただけますか」是「待(ま)ってもらえますか」的敬语说法，店员、窗口职员常用，请求您等一会儿。

## 生词
```

### #5 来週の飲み会、来られそうですか？
```
## 听懂
原文：来週(らいしゅう)の飲(の)み会(かい)、来(こ)られそうですか？
意思：下周的聚餐，你看起来能来吗？
要点：「来(こ)られ」是「来(く)る」的可能形（能来），不是尊敬语；「〜そう」表示「看起来有可能」，是在委婉地问你方不方便。

## 回复建议
1. 丁寧⭐｜はい、【行(い)けそう】です。〇〇さんも行(い)きますか？
   → 嗯，应该能去。你也去吗？
2. カジュアル｜うん、【行(い)けそう】！〇〇も行(い)く？
   → 嗯，应该能去！你也去吗？
3. かんたん｜はい、【行(い)きます】。
   → 好的，我去。
推荐理由：对方用了「〜ですか」，按同等礼貌程度回答；若想拒绝可说「すみません、【その日(ひ)は難(むずか)しそう】です」（抱歉，那天可能不太方便）。

## 生词
- 飲(の)み会(かい)：聚餐、酒局
- 〜そう：看起来、似乎（表示可能性）
- 難(むずか)しい：（这里指）不方便、很难办到
```

```

意思：这份资料，能请你在明天之前整理好吗？
要点：「まとめてもらえますか」是礼貌的请求句式，字面是「能请你整理吗」，实际是上司在布置任务，通常要答应。

   → 嗯，知道了。明天之前整理好。
3. かんたん｜はい、わかりました。
   → 好的，我明白了。
推荐理由：你说明对方是上司，所以用丁寧；若来不及可说「申(もう)し訳(わけ)ありません、【明日(あした)の夕方(ゆうがた)】まででもよろしいでしょうか」（抱歉，可以到明天傍晚吗）。

## 生词
- まとめる：整理、汇总
- 承知(しょうち)しました：明白了、遵命（对上司比「了解」更得体）
- お渡(わた)しする：交给（谦让说法）
```

### #7 日本に来てどれくらいですか？

```
意思：你来日本多久了？
要点：「来(き)て」后面省略了「から」或「経(た)つ」，完整说法是「日本に来てからどれくらいですか」。

3. かんたん｜【半年(はんとし)】です。
   → 【半年】了。
推荐理由：对方用了「〜ですか」，按同等礼貌程度回答；若想说刚来不久可用「まだ【一(いち)か月(げつ)】です」。

## 生词
- どれくらい：多久、多少（问时间或程度）
- 〜ぐらい：大约、左右
- 半年(はんとし)：半年
```

### #14 ってか、昨日のやつどうなった？
```

## 生词

- 途中(とちゅう)：进行到一半、中途
- ってか：话说、不过（「っていうか」的口语形式）
```
