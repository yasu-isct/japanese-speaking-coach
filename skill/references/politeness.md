# 敬语判断规则

用途：决定「回复建议」里哪一条标 ⭐，以及三种回复各自的礼貌上限/下限。
SKILL.md 中的推荐规则是本文件的摘要；两者冲突时以本文件为准。

## 1. 判断流程（按顺序，命中即停）

| 步 | 依据 | 结果 |
|---|---|---|
| 1 | 用户明确说想要最简单的说法，或表示紧张、说不出来（「急」「快」「说不出来」等） | ⭐ かんたん |
| 2 | 用户说明了对象或场景（如「对方是上司」「在面试」） | 查 §2 对象表 |
| 3 | 对方用了丁寧语标记（§3.1） | ⭐ 丁寧 |
| 4 | 对方用普通体，**且**至少有一个口语标记（§3.2） | ⭐ カジュアル |
| 5 | 以上都不满足（普通体但无口语标记、句尾省略、只有一个词） | ⭐ 丁寧（默认） |

要点：
- **第 4 步需要口语标记，不能只看普通体。**「大丈夫？」「どうした？」这类短句，上司、陌生人、朋友都可能说，看不出关系。
- **感叹词不算语体标记**：「いや」「えー」「あ」「うん」单独出现时不作判断依据。
- 同一对话中已经确定过对象的，沿用之前的判断，不必每句重新推断。
- 输入有语音识别错字时，先按推测的原文判断（如「何時から出したっけ」按「何時からでしたっけ」→ 丁寧）。

## 2. 对象表（用户说明对象时使用）

| 对象 | ⭐ | 备注 |
|---|---|---|
| 上司、老师、教授、客户、面试官 | 丁寧 | 可用 §4 的常用敬语 |
| 先輩、年长者、打工店的店长 | 丁寧 | 即使对方用普通体（见 §5） |
| 店员、窗口职员、初次见面的人 | 丁寧 | 回答宜短 |
| 同期入职的同事、同研究室的同学 | 用户说「关系熟」→ カジュアル；否则看对方用语（§1 第 3–5 步） | |
| 朋友、同龄同学、後輩 | カジュアル | |
| 家人、恋人 | カジュアル | |

## 3. 语体标记

### 3.1 丁寧语标记（命中任一即可）
- 句尾 です / ます / でした / ました / でしょうか / ませんか
- ございます、〜でございます
- 尊敬语：お〜になる、〜られる（尊敬用法）、いらっしゃる、おっしゃる、召し上がる、お持ちですか 等
- 谦让语：お〜する、〜ていただく、伺う、申す、いたす、おる
- 职场固定表达：お疲れ様です、失礼します、よろしくお願いします

### 3.2 口语标记（普通体 + 命中任一 → カジュアル）
- 俗语/强调：マジ、めっちゃ、すごい（作副词）、やばい、超〜、ガチ
- 句尾：普通体 + 终助词（〜だよ、〜だね、〜よね、〜な）、〜じゃん、〜っしょ、〜の？、〜くない？
- 缩约：〜てる、〜てて、〜ちゃう/〜ちゃった、〜とく、〜じゃない（作「〜ではない」）、ってか、っていうか
- 称呼：直呼名字、〜ちゃん、〜くん（对用户的称呼）
- 否定疑问邀约：〜行かない？、〜しない？

## 4. 各风格的礼貌上限 / 下限

### 丁寧
- 基础：です/ます体。
- **可用**的敬语（常用、不易出错）：いただきます、申します、伺います、いたします、おります、承知しました、お願いできますか。
- **避免**大段的尊敬语/谦让语堆叠和二重敬语。N4–N2 学习者说不顺，说错了反而比简单的です/ます更失礼。
- 场景为面试、对客户时，可以多用上面的谦让语，但仍以一句话说得出口为准。

### カジュアル
- 普通体 + 自然口语（〜てる、〜じゃん、〜よね）。
- **避免**：粗鲁用语（おまえ、うるせー、〜ぜ）；性别色彩强的句尾（〜わ、〜かしら、〜だぜ），学生的性别未知，用中性说法；方言（除非对方在用）。
- 对象明确是上司、老师、客户、面试官、店员等服务人员时仍然给出（供学习普通体），但按 SKILL.md 加「⚠ 对此对象不要用」。「对象明确」以学生说明或店员服务用语为准，不能只凭对方用了敬语就判断。

### かんたん
- 只用 N4 以内的词和语法，最多 2 个短句、合计约 15 个假名以内，比丁寧明显更短。
- 语体跟随 ⭐：⭐ 是カジュアル时用普通体，其余情况用です/ます。
- です/ます 对谁说都不会失礼，所以是保底的默认值。

## 5. 不对称关系（重要）
「对方用什么语体，就用什么回」只适用于**对等关系**或**关系不明**的情况。
上下关系中礼貌是不对称的：上司、先輩、老师、年长者对你用普通体是正常的，**你仍然用丁寧**。
因此用户说明了对象时（§1 第 2 步），对象表优先于对方的用语。

## 6. 推荐理由的写法
推荐理由用一句学生能看懂的话写出依据：对方的具体说法，或学生说明的对象。
- **不要**写步骤编号、章节号（§）或文件名——这些是给你的内部规则，学生看不懂。
- **不要**写「若对方是上司/不熟，就改用丁寧」这类语体切换提醒：三条回复本身已经给出了不同语体。

示例（依次对应 §1 的第 3、4、2、5 步）：
- 「对方用了『〜ですか』，按同等礼貌程度回答。」
- 「对方用了『マジ』『〜くない？』，是朋友间的说法。」
- 「你说明对方是上司，即使对方说话随意也用丁寧。」
- 「看不出你们的关系，用丁寧最稳妥。」

## 7. 常见失礼与错误（生成丁寧回复和复盘纠错时参考）

| 错误说法 | 问题 | 改为 |
|---|---|---|
| ご苦労様です（对上司） | 上对下的慰劳语 | お疲れ様です |
| 了解です / 了解しました（对上司、客户） | 不够郑重 | 承知しました / かしこまりました |
| おっしゃられる、お伺いさせていただく | 二重敬语 | おっしゃる、伺います |
| 〜させていただきます（滥用） | 显得生硬啰嗦 | 〜します / いたします |
| なるほどですね（对上司） | 评价对方的语感 | そうなんですね |
| 单说「大丈夫です」回答「要不要」 | 听者分不清是「要」还是「不要」 | 不要：いえ、大丈夫です（前面加「いえ」）；要：はい、お願いします |
| 袋に入れてお願いします | 「〜てください」和「〜をお願いします」两个句型拼在一起，语法不通 | 袋に入れてください / 袋をお願いします |
| 顾客对店员说「お待たせしました」「かしこまりました」 | 角色颠倒：这是店员对顾客的用语 | はい、わかりました |
