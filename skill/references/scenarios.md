# 情景库（C. 情景陪练）

学生说「陪练」但没指定场景时，列出下表让学生选（可以回编号或名称）。

| 编号 | 场景 | 等级 | 学生要用的语体 |
|---|---|---|---|
| S1 | 便利店结账（コンビニ） | N4 | 丁寧（简单） |
| S2 | 约朋友吃饭（友達との約束） | N4 | カジュアル |
| S3 | 打工面试（アルバイトの面接） | N3 | 丁寧 + 基本谦让 |
| S4 | 午休和同事闲聊（職場の雑談） | N3 | 丁寧（轻松） |
| S5 | 医院看病（病院） | N3 | 丁寧 |
| S6 | 找老师商量延期（先生に相談） | N3 | 丁寧 + 请求表达 |
| S7 | 中介找房子（不動産屋） | N2 | 丁寧 |
| S8 | 求职面试（就活の面接） | N2 | 丁寧 + 谦让 |

## 怎么使用每个场景

- **开场白**：逐字使用，保证同一场景每次开头一致（便于测试和对比）。
- **流程**：每轮推进一个节点，台词只说一句。学生的回答偏离时，先在角色里自然回应，再拉回下一个节点。节点不必全部走完。
- **变化**：每次陪练从「变化」中随机选一个加进流程，让重复练习不至于背台词。学生说「简单模式」时不加变化。
- **你的语体**：按「你对学生」一栏说话，这本身就是听力材料。
- **难度调节**：学生连续 2 次卡住（输入「？」「不知道」或求助），之后的台词改得更短、更常用，但不跳出角色。
- **💡 提示**：只在学生的回答会造成误解或明显失礼时给。各场景「常见失礼/误解」列出了典型情况；同等严重的其他问题也可以给。小错误留到复盘。
- **不编造学生信息**：问到学生的经历、名字、国籍等，由学生自己回答；学生答不上来时按 A 模式给建议，个人事实用【】。
- **结束**：按 SKILL.md C 模式第 6 条——流程节点走完或达到「完成条件」时，这一轮的台词就是收尾台词，不再追加新问题；第 8 轮无论如何都要收尾。收尾台词后单独一行输出：`（场景结束。输入「复盘」查看纠错和生词卡。）`
- **变化不延长对话**：加入的「变化」占用流程里的一个节点，不额外增加轮数。

## S1 便利店结账（コンビニ）
- **等级**：N4
- **你扮演**：便利店店员｜**学生扮演**：顾客
- **你对学生**：店员服务敬语｜**学生应使用**：丁寧（「はい、お願いします」级别即可）
- **任务**：回答店员的每个问题，完成付款。
- **开场白**：いらっしゃいませ。こちらのお弁当(べんとう)、温(あたた)めますか？
- **流程**：
  1. 要不要加热
  2. 要不要袋子（「袋(ふくろ)はご利用(りよう)ですか」）
  3. 有没有积分卡 / App
  4. 付款方式（「お支払(しはら)いはどうなさいますか」）
  5. 报金额、找零、收据
- **变化**（选一）：加热需要等一会儿，请学生在旁边稍等；学生选的电子支付读取失败，请换一种付款方式；问要不要筷子或勺子。
- **听力难点**：〜はご利用ですか／〜円(えん)になります／〜円のお返(かえ)しです／レシートはご利用ですか
- **常见失礼/误解**：单说「大丈夫です」，店员分不清要还是不要（应加「いえ、」或说「お願いします」）。
- **完成条件**：找零完成。找零那一句之后，下一轮直接用「ありがとうございました。」收尾（不要再问小票、筷子等新问题）。

## S2 约朋友吃饭（友達との約束）
- **等级**：N4
- **你扮演**：学生的同学兼朋友（同龄）｜**学生扮演**：朋友
- **你对学生**：普通体、口语｜**学生应使用**：カジュアル
- **任务**：和朋友定下吃饭的日期、时间、地点和要吃的东西。
- **开场白**：ねえ、今週(こんしゅう)の金曜(きんよう)って空(あ)いてる？
- **流程**：
  1. 问学生有没有空
  2. 提议吃什么（「〜とかどう？」）
  3. 定时间
  4. 定碰头地点（站的检票口等）
  5. 最后确认一遍，道别
- **变化**（选一）：学生那天正好有事，需要改天；朋友想再叫一个人一起来；朋友提议的店学生不能吃（如辣、生鱼），需要换。
- **听力难点**：〜って空いてる？／〜とかどう？／〜にしない？／じゃあ〜で！
- **常见失礼/误解**：拒绝时直接说「行きたくない」（显得冷淡，应说「ごめん、その日はちょっと…」）；时间或地点说得含糊，导致约定不清。
- **完成条件**：日期、时间、地点三项都已确定，互相道别。

## S3 打工面试（アルバイトの面接）
- **等级**：N3
- **你扮演**：餐厅店长（面试官）｜**学生扮演**：应聘打工的留学生
- **你对学生**：丁寧（店长对应聘者，礼貌但不过分郑重）｜**学生应使用**：丁寧 + 基本谦让（〜と申(もう)します、よろしくお願いします）
- **任务**：自我介绍，说明每周能上班的时间和日语水平，最后问一个问题。
- **开场白**：今日(きょう)は来(き)てくれてありがとうございます。まず、簡単(かんたん)に自己紹介(じこしょうかい)をお願(ねが)いできますか？
- **流程**：
  1. 自我介绍
  2. 为什么想在这家店打工
  3. 每周能上几天、哪几天、几点到几点
  4. 有没有打工经验
  5. 「何(なに)か質問(しつもん)はありますか」
  6. 告知之后联系
- **变化**（选一）：问留学生的打工时间限制（资格外活动每周 28 小时）；问能不能周末和节假日上班；问什么时候可以开始。
- **听力难点**：シフトはどのくらい入(はい)れますか／週(しゅう)に何日(なんにち)くらい／いつから働(はたら)けますか／何か質問はありますか
- **常见失礼/误解**：自称「俺」或用「〜っす」；能上班的时间只说「大丈夫です」，没说具体日期时间（店长无法排班）；面试结束不说「よろしくお願いします」。
- **完成条件**：店长说「結果(けっか)は〜までに連絡(れんらく)します」，学生道谢告别。

## S4 午休和同事闲聊（職場の雑談）
- **等级**：N3
- **你扮演**：同一部门的日本同事，比学生早一年入职（先輩）｜**学生扮演**：同事
- **你对学生**：轻松的です/ます，偶尔夹普通体｜**学生应使用**：丁寧（轻松）。即使先輩说普通体，学生也用です/ます（politeness.md §5）
- **任务**：午休时和先輩自然聊天，至少把话题抛回给对方一次。
- **开场白**：お疲(つか)れさまです。お昼(ひる)、もう食(た)べました？
- **流程**：
  1. 午饭吃了吗、吃了什么
  2. 周末做了什么
  3. 问学生的家乡
  4. 在日本生活习惯了吗
  5. 推荐附近好吃的店
  6. 「そろそろ戻(もど)りましょうか」
- **变化**（选一）：先輩聊起自己的爱好，问学生有没有兴趣；先輩问学生过年回不回国；先輩随口用普通体说「マジで？」，看学生是否仍保持です/ます。
- **听力难点**：主语省略／〜っけ／〜じゃないですか（寻求同意）／相槌（そうなんですね、へえ）
- **常见失礼/误解**：先輩用了普通体，学生也跟着改用普通体（上下关系不对称）；对先輩说「なるほどですね」「了解です」。
- **完成条件**：先輩提出回去工作，学生回应。

## S5 医院看病（病院）
- **等级**：N3
- **你扮演**：先是挂号窗口职员，问诊时换成医生（换角色时用一行括号说明，如「（医生来了）」）｜**学生扮演**：患者
- **你对学生**：丁寧｜**学生应使用**：丁寧
- **任务**：完成挂号，向医生说清楚症状，听懂药怎么吃。
- **开场白**：こんにちは。初診(しょしん)ですか？保険証(ほけんしょう)はお持(も)ちですか？
- **流程**：
  1. 挂号：是否初诊、保险证
  2. 填问诊表（简单问一句今天哪里不舒服）
  3. 医生问症状：哪里、怎么样
  4. 从什么时候开始、有没有发烧
  5. 有没有过敏、在吃什么药
  6. 诊断和药的服用方法（「食後(しょくご)に飲(の)んでください」）
- **变化**（选一）：学生忘带保险证；医生要求验血或拍片；药一天吃三次、要吃五天。
- **听力难点**：いつからですか／熱(ねつ)はありますか／アレルギーはありますか／食後に／お大事(だいじ)に
- **常见失礼/误解**：症状说错部位或程度（如把「喉(のど)」说成「首(くび)」），导致医生误解；没听懂服药方法就说「はい」。
- **完成条件**：医生说完服药方法，说「お大事に」。

## S6 找老师商量延期（先生に相談）
- **等级**：N3
- **你扮演**：大学老师（学生的课程老师）｜**学生扮演**：留学生
- **你对学生**：丁寧，略带老师的口吻｜**学生应使用**：丁寧 + 请求表达（〜ていただけませんか、〜てもよろしいでしょうか）
- **任务**：说明情况，请求延长报告的截止日期，确认新的截止日期。
- **开场白**：はい、どうぞ。どうしましたか？
- **流程**：
  1. 学生说明来意
  2. 老师问理由
  3. 老师问需要延长多久
  4. 老师给出条件或新日期
  5. 学生确认
  6. 道谢、离开（「失礼(しつれい)します」）
- **变化**（选一）：老师只同意比学生要求更短的延期，学生需要接受或再商量；老师不同意延期，但允许先交一部分；老师要求学生发邮件说明。
- **听力难点**：〜ということですね／〜までなら大丈夫(だいじょうぶ)ですよ／今回(こんかい)だけですよ
- **常见失礼/误解**：用命令式请求「延ばしてください」；对老师说「了解です」「ご苦労様です」；没说理由就直接要求延期。
- **完成条件**：新的截止日期已确认，学生说「失礼します」。

## S7 中介找房子（不動産屋）
- **等级**：N2
- **你扮演**：房产中介｜**学生扮演**：找房子的留学生
- **你对学生**：丁寧 + 服务敬语｜**学生应使用**：丁寧
- **任务**：说明预算和条件，听懂费用说明，预约看房。
- **开场白**：いらっしゃいませ。本日(ほんじつ)はどのようなお部屋(へや)をお探(さが)しですか？
- **流程**：
  1. 想住的地区、离车站多远
  2. 预算（房租、是否含管理费）
  3. 户型（1K、1LDK 等）
  4. 介绍一套房：押金、礼金、管理费
  5. 外国人入住的手续（保证公司、在留卡）
  6. 预约看房（内見(ないけん)）
- **变化**（选一）：学生想要的条件超出预算，中介提议放宽条件；房东要求日本人担保人；中介说「人気(にんき)の物件(ぶっけん)なので早(はや)めに」，催学生决定。
- **听力难点**：敷金(しききん)・礼金(れいきん)／管理費(かんりひ)込(こ)み／駅徒歩(えきとほ)〜分(ふん)／保証会社(ほしょうがいしゃ)／内見
- **常见失礼/误解**：没确认初期费用的总额就答应；把「礼金」理解成会退还的押金。
- **完成条件**：学生说出看房的日期时间后，中介复述确认并道谢，这一句就是收尾台词。

## S8 求职面试（就活の面接）
- **等级**：N2
- **你扮演**：日本公司的人事面试官｜**学生扮演**：求职的留学生
- **你对学生**：郑重的丁寧｜**学生应使用**：丁寧 + 谦让（〜と申します、御社(おんしゃ)），注意不要滥用「〜させていただきます」
- **任务**：完成一场约 6 问的一面：自我介绍、志望动机、学生时代最投入的事、追问、在日本工作的理由、反问。
- **开场白**：本日(ほんじつ)はよろしくお願(ねが)いします。では、まず一分(いっぷん)ほどで自己紹介(じこしょうかい)をお願いします。
- **流程**：
  1. 自我介绍
  2. 志望动机（为什么是本公司）
  3. 学生时代最投入的事（ガクチカ）
  4. 追问一次（「なぜ」「具体的(ぐたいてき)には」）
  5. 为什么想在日本工作、将来想做什么
  6. 「最後(さいご)に何(なに)か質問(しつもん)はありますか」
- **变化**（选一）：追问学生经历中的困难和解决办法；问对加班或调动的看法；问日语以外的语言能力。
- **听力难点**：〜について詳(くわ)しく教(おし)えてください／具体的には？／弊社(へいしゃ)／最後に何か質問はありますか
- **常见失礼/误解**：口头说「貴社(きしゃ)」（书面用语，口头应说「御社」）；反问时说「特にありません」（显得没兴趣）；用「〜っす」「〜みたいな」等口语。
- **完成条件**：面试官说「本日はありがとうございました。結果は後日(ごじつ)ご連絡します」，学生道谢。
