# 资料选择与更新：界面对照

固定输入为公开的课程TTS回答及其参考片段。改前用 `495f555` 的 material_view.py，改后用D-027；相同820×600客户区、同一资料路径与源片段。均在所有屏幕外映射，以自身HWND绘图，前台窗口句柄不变，没有系统鼠标点击或文件选择对话框自动弹出。

本机图片：`logs/ui-iterations/materials-before-20261026-201648/materials.png`、`materials-after-20261026-201649/materials.png`；另查520×540窄窗 `materials-after-narrow-20261026-201858/materials.png`。早期截图已保留，最终对照以上述相同路径版本为准。

| 原则 | 改前 | 改后与限制 |
|---|---|---|
| 可读性 | 只有片段和路径 | 上方目录/动作/状态，下方片段滚动；820和520宽截图中说明可换行。窄窗只显示部分片段，需要滚动；没有隐藏内容。 |
| 信息层级 | 目录与片段放在同一文字区 | 当前选择固定在上方；当前回答若来自旧目录，正文另标旧目录，避免误读。已读文件数帮助发现没读入资料。 |
| 遮挡 | 点击“资料”才开窗口 | 仍只由用户点击打开，不随回答弹窗。生产默认窗口720×480→780×600，以容纳控制区；对照截图统一820×600。 |
| 对比度 | 白底黑字 | 系统控件与白底正文；截图可辨认，未宣称完整无障碍合规。 |
| 字号 | 正文12pt | 正文仍12pt，标题/按钮使用系统字号；未缩小正文。支持窗口缩放换行，最小520×400。 |
| 操作步数 | 窗口内不能换目录或刷新，需要命令/重启 | 从主窗到刷新是“资料→重新读取”2次点击；选择目录是“资料→选择→系统确认”，导航步数依目录位置而定。系统选择对话框未自动实点。 |

截图证明布局，离线测试验证按钮后的工作线程、缓存切换和设置保存。真人通话中的操作便利仍待集中体验。
