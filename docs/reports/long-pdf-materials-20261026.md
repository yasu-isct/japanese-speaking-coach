# 长PDF按版面空行分段（D-036）

本步改善同一页里多个主题挤在一个资料片段的问题，不改生成提示或个人事实规则。固定四页公开合成讲义，二十个小节，英语/日语/中文资料和十六个日语问题。原实现把整页文字按700字切开；多语言已经能找全16题的关键事实，但只有9题在一个选中片段内保留完整小节，资料窗首屏也常先显示无关介绍。

## 方法与边界

超过700字的页尝试[pypdf的layout模式](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)，仅用版面空行推测分段边界。普通提取和layout去掉空白后的字符序列必须完全相同，否则放弃推测，保留原页文字。采用边界时再映射回原提取字符串，**不使用layout生成的文字替换原文**，避免改变词内空格或丢失旋转内容。PDF没有可靠的段落语义层，这仍是对常见单栏版式的启发式方法。

页码保持物理页；分段后标成`第3页・片段3`。片段序号表示本次提取的块顺序，包含可能的页眉/页脚，不是印刷段落编号。没有可靠空行时保留原页；超过700字的单个长块仍沿用有界切分，尚未做句子级衔接。短页保留旧载荷与来源ID。

沿用隐藏子进程、15秒超时、原有字数/内容流/页数约束。额外版面分析仅对≤20,000字、≤8,000操作的页进行；layout结果限制长度和每页最多64块，超过条件即保留原文字。解析失败或文字顺序不同也回退，读取提示指出页码。没有新增依赖、模型、OCR或查看器；这些限制不是进程级硬内存配额。
