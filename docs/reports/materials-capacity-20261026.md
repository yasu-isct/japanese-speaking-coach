# 资料容量、读取进度与取消（D-034）

本步检查较大外部资料文件夹的完整读取，不重新评测个人资料真实性。固定生成100份虚构讲义，每份16段，共198,000字；生成器为`tools/eval_materials_scale.py`，结果保存每份输入的SHA。唯一标识查询用于检查索引覆盖，不能当作自然语言回答准确率。

每项建索引只测一次，同一机器，文件缓存和其它负载未控制；索引耗时增长伴随读取量增长。十问p95取最大值。这些数字不包含ASR、生成API或可见绘制。

默认上限由64文件/10万字/256片段调整为128文件/40万字/2048片段。单份Word/PDF提取仍限制10万字；md/txt单文件64KB、Word/PDF文件10MB、扫描目录2048条目与4层保持。每次回答仍最多4个片段/1800正文字，不随资料库扩容而扩大。超过片段上限的最后一个文件现在明确标记“只读取了前一部分”，刚好达到上限且没有遗漏时不误报。

资料窗口显示文件读取数和多语言索引阶段，可取消；关闭忙碌窗口也会取消。新快照完整后才替换，取消保留原资料、缓存和偏好。PDF子进程收到取消后终止并回收；没有窗口或查看器。当前正在处理的小段工作完成后响应取消，不承诺任意时刻立即停止。

## 资源与并行检查

多语言全进程工作集由476,250,112增至500,916,224字节；私有提交内存由1,236,463,616增至1,261,273,088字节，峰值工作集约544MB。包含Python、模型和运行时，不能说成单独索引占用，也不能把私有提交内存说成实际物理驻留量。关键词模式完整索引工作集44,421,120字节。
