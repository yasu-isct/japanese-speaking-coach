# 复盘入口：界面对照

改前3693f0d只有命令行导出。主窗对照使用相同公开TTS结果、900×419客户区、字体与不透明背景；新增窗口使用公开虚构存档，只有2条字幕、2轮建议、2条去重查词，没有录音或真人信息。全部在虚拟桌面外捕获自身HWND，没有打开浏览器、Explorer、系统文件选择框，没有改变前台窗口。

改前主窗：`logs/showcase/20261026-202802-001591/references-1.png`；改后：`logs/showcase/20261026-203321-024759/references-1.png`。新窗口最终四状态在 `logs/ui-iterations/review-picker-20261026-203339/`，公开副本为 `docs/images/live-review-picker.png`。初版窄窗口会挤掉底部动作，已改为优先保留操作区、缩小可滚动列表；初版证据保留在 `review-picker-20261026-203313/narrow.png`。

| 原则 | 改前 | 改后与限制 |
|---|---|---|
| 可读性 | 需读命令输出寻找文件 | 按时间列出存档，完成后显示字幕/建议/卡片数量；780×570和620×460均可读，长路径自动换行。 |
| 信息层级 | 没有窗口入口 | 选择存档→生成→打开，未选或未生成的按钮禁用；无查词时说明0卡，不把0卡当作失败。 |
| 遮挡 | 主窗无复盘入口 | 工具栏多一个“复盘”，900像素主窗未增高、未遮住原文字；仅用户点击或专用脚本启动窗口，导出不自动打开结果。 |
| 对比度 | 沿用主窗配色 | 复盘使用系统控件，选中行有系统高亮；截图可辨认，未宣称无障碍合规。 |
| 字号 | 命令行依终端设置 | 标题16pt，其余系统字号；窄窗不缩字体，列表改为滚动。 |
| 操作步数 | 需要输入命令和完整路径 | 主窗“复盘→选一行→生成→打开”4次点击；课后可直接双击专用脚本。其它文件夹仍需系统导航。 |

实际工作线程读取与导出完成，虚构样本2字幕/2轮/2卡，源文件哈希不变。最终单次生成到UI轮询取到结果60.49ms，不是API或字幕延迟。窗口关闭后再开会刷新列表，保留每次新建导出的方式。真人操作和Anki桌面导入留到集中验收。
