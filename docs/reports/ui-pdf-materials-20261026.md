# PDF页码与读取提示：界面检查（D-033）

按`docs/ui-principles.md`检查，同一公开虚构资料目录包含两份文字PDF与一份仅图片PDF，同一个提交期限问题；不调用API，画面为本地检索和引用状态的合成输入。

| 项目 | 改前 / 首版发现 | 最终结果 |
|---|---|---|
| 可读性 | PDF都忽略，无片段 | 默认窗能看到第1页全部提取文字；520×540能看到页码和正文开头，余下滚动查看 |
| 信息层级 | 首版扫描页提示占据上半窗，窄窗首屏看不到来源 | 有命中时先显示当前片段，再显示其它文件的读取提示；没有命中时读取提示仍在前 |
| 遮挡 | 资料窗820×600，窄窗520×540 | 不增加窗口面积，不改字幕主窗；不弹PDF查看器 |
| 对比度 | 黑色正文/白底、系统控件 | 沿用原色，读取问题有文字说明，不仅靠颜色 |
| 字号 | 正文12pt | 不缩小字号；长页通过滚动阅读，页眉页脚也可能进入PDF文字 |
| 操作步数 | 文件夹选择/刷新已存在 | 放入PDF后一次刷新，原按钮与流程不增加步骤 |

解析使用Windows隐藏子进程，实际读取三份固定文件约995.63ms，前台HWND保持不变；不是可见建议延迟。所有UI截图位于虚拟桌面之外、不激活、穿透，仅PrintWindow本进程HWND，没有桌面像素。
