# 资料后台启动（D-035）

启动字幕窗口时先建立不读取磁盘的空资料快照，让窗口和音频线程先开始。后台先读取关键词资料，再加载已选择的本机多语言模型；两次都在完整快照建好后切换。启动本身不下载模型、不改保存的偏好。

主窗用一行提示区分“资料尚未读取”和“已读取，正在准备多语言”。详细进度及取消放在用户打开的“资料”窗，沿用D-034控件。取消早期读取时回答暂不参考文件；关键词已就绪后取消多语言准备，则继续用关键词。模型失效时同样保留关键词，并提示在多语言设置中检查。关闭应用会取消后台准备；用户选择其它目录会取消旧启动任务，旧任务不能覆盖新的选择。

`--no-window`命令行运行保持先读完资料再开始音频的行为，使固定文件回放/评测输入不因后台准备进度不同而变化。普通GUI在资料未就绪时可能已经听到问题，此时建议不参考文件；状态提示明确说明，不把空快照伪装成检索过而无答案。
