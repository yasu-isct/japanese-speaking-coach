# 从资料窗口管理本地模型：界面对照

改前父窗口 `logs/ui-iterations/materials-d031-before-20261026-211120/materials.png`，改后 `materials-d031-after-20261026-211617/materials.png`：同一公开TTS出处、820×600客户区，只增加“多语言查找…”入口。新设置窗口用实际本地模型、公开虚构资料和临时偏好检查，结果在 `logs/ui-iterations/model-controls-20261026-211816/`。

初版640×480/560×450的窄窗会截断状态文字，人工查看发现后已修复。旧的机械检查只看分配高度，漏掉了文字裁剪；最终改查请求高度，并逐张看图。当前默认640×520、最小560×500；完成后隐藏忙碌条，路径用可复制、按字符换行的文本框。早期图保留在 `model-controls-20261026-211612/`。

| 原则 | 改前 | 改后与限制 |
|---|---|---|
| 可读性 | 模型需手动准备、启动参数控制 | 当前方式、路径、开启/关闭、下载大小和状态都可见；默认/窄窗状态完整。 |
| 信息层级 | 资料窗口只有文件夹操作和出处 | 父窗口多一个入口；模型操作单独窗口，出处正文区域不减少。 |
| 遮挡 | 只有用户点资料才开窗口 | 新窗口仍只由用户点击打开，后台完成不弹额外窗口；关闭正在处理的窗口会请求取消。 |
| 对比度 | 系统黑字浅底 | 保持系统配色，忙碌时按钮禁用，取消按钮可用；没有无障碍合规声明。 |
| 字号 | 沿用系统控件与正文12pt | 标题16pt，路径Consolas 10pt可复制；没有为容纳错误信息缩小文字。 |
| 操作步数 | 需下载文件并输入带路径的命令，每次启动指定 | 初次“资料→多语言查找→下载并开启”3次点击；已有模型选目录；之后自动沿用选择，关闭也在同一处。系统目录对话框未自动操作。 |
