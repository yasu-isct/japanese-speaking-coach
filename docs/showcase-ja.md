# Japanese Speaking Coach — リアルタイム字幕と返答候補

> 画面はすべて TTS 音声による再生・個人情報なし（撮影条件は [`docs/images/README.md`](images/README.md)）。

## できること

会話中、画面下の小さなウィンドウが次の 3 つを支える。

1. **聞き取る**：PC で再生中の音声（ビデオ通話・動画）かマイクを GPU 上で文字起こしし、難しい漢字にだけふりがなを付ける。
2. **返す**：相手が話し終えて一息つくと、そのまま口に出せる返答を 丁寧／カジュアル／かんたん の 3 つ出す。推奨は ⭐ ひとつ、相手が店員や上司ならカジュアルに ⚠。規則は第 1 段階の Claude Skill をそのまま読み込んで使う。
3. **覚える**：字幕の履歴で単語を選ぶと読みと文脈上の意味が出る。録音版で起動すると音声・字幕・提案を保存する。

## 数字（TTS 10 文・1 回の実行・RTX 5060 Laptop）

| 区間 | p50 | p95 |
|---|---|---|
| 音声認識（large-v3-turbo） | 258 ms | 333 ms |
| API 往復（deepseek-flash） | 1565 ms | 1986 ms |
| 描画 | 71 ms | 102 ms |
| 最後の字幕 → 返答候補が出るまで | 2.46 s | 2.90 s |

話し終えてから最初の字幕まで 0.81 s。単体テスト 78 件、設計判断の記録 D-001〜D-020（20 件）。

## できないこと（正直に）

- 数字は TTS 音声での測定。作者本人は実際の動画と 89 分のオンライン授業で使ったが、第三者の試用と日本語母語話者のレビューはまだ。
- 返答の質は DeepSeek に依存し、⭐ を付け忘れることが多い（授業では 628 回中 394 回、規則どおり 丁寧 で補完）。
- 中国語が混ざる会話は保留中。Windows のみ。

## 次にやること

⭐ の付け忘れを減らす、個人プロフィールと過去の会話を使った返答、第三者による試用。
