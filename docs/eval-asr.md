# jsc_live 语音识别小型评测（2026-10-24）

> 目的：给实时字幕原型一个**可复现的基线数字**，而不是证明它"够好"。
> 结论只适用于下面写明的条件：合成语音、安静、一句一段。没有真人语音的数字。

## 条件

| 项目 | 内容 |
|---|---|
| 句子 | 28 句：`tests/sample_dialogues.md` 的 20 句 + `skill/references/scenarios.md` 8 个情景的开场白（`tests/asr_eval/sentences.tsv`）。#19 原本是故意写错的识别结果，这里用它想表达的正确句子作参考答案 |
| 音频 | Windows 自带的 3 个日语语音（Haruka、Ayumi 女声，Ichiro 男声）合成，共 84 条，16 kHz 单声道。不含任何真人录音，没有下载数据集（`tools/tts_winrt.ps1`） |
| 识别路径 | 与实时应用相同：WAV → `Segmenter`（分句）→ `Transcriber`（kotoba-whisper-v2.0-faster，beam 5）。不是直接调用模型，分句错误也会计入 |
| 硬件 | RTX 5060 Laptop 8 GB，CUDA float16，Windows 11 |
| 复现 | `python tools/eval_asr.py --synth`，然后 `python tools/eval_asr.py`；逐条结果在 `tests/asr_eval/results.csv` |

**两种字错误率（CER）**
- **CER**：表面文字，NFKC 规整、去掉标点后逐字比对。
- **读音 CER**：先用 MeCab（UniDic）把两边都转成平假名再比对。它不计「お疲れ様 / お疲れさま」「一分 / 1分」这类**写法不同但读音相同**的差异，但也不计同音错字（初診 → 初心）。两个数一起看才完整。

## 错误分析（84 条中 30 条不完全一致）

| 类型 | 例子（参考 → 识别） | 出现 | 说明 |
|---|---|---|---|
| 写法差异 | お疲れ様 → お疲れさま；ひま → 暇；行かない → いかない；一分 → 1分；一日 → 1日；ってか → てか | t08、t12、s08、t14 × 3 语音；t10 Haruka/Ichiro | 读音相同或几乎相同，读音 CER 不计。对字幕阅读影响小 |
| 同音错字 | 初診 → 初心 | s05 × 3 | 读音相同、意思不同。需要上下文才能区分 |
| 真实识别错误 | 来れなくても → くれなくても；何時から → いつから；お箸おつけ → お箸を付け／お箸をつけ | t16、t19、t02 × 3 | 读音也错，会误导学习者。「来れる」是ら抜き言葉，「何時」本身有なんじ/いつ两种读法，可能与合成语音的读法有关 |
| 可能是合成语音读错 | 温め → ぬくめ；一日 → ついたち（只出现在 Ayumi） | s01 × 3、t10 Ayumi | 识别结果可能忠实反映了 TTS 的读音。没有逐条听音频核对，**不能确定是识别错误** |
| 语气丢失 | 食べました？ → 食べました。 | s04 | 疑问语调没有反映在标点上。CER 去掉了标点，所以不计入 |

## 局限（还没验证的）

- **没有真人语音**：合成语音发音清晰、语速稳定、没有口癖和噪声，结果会比真人乐观。
- **没有噪声 / 背景音乐 / 多人说话**：分句器是能量阈值，这些情况下预期会变差。
- **句子是自己写的**：28 句都是短的生活对话，不代表长篇、专业词汇或方言。
- **样本小**：84 条，CER 差 0.1–0.2 个百分点没有统计意义；三种语音之间的差异不能解读为模型对男女声的偏好。
- 没有和其他模型（Whisper large-v3、ReazonSpeech）对比。
