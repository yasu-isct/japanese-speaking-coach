# 试用指南（发给试用的朋友）

谢谢你帮忙试用！大约需要 **20–30 分钟**。这是一个帮在日本生活的中文母语者「听懂、接上、记住」日语对话的 Claude 小工具。

## 1. 安装（5 分钟）

需要 Claude 的 Pro / Max / Team 账号，并在设置里开启代码执行（Code execution）。

1. 从作者那里拿到 `japanese-speaking-coach.zip`。
2. 打开 Claude → 设置（Settings）→ Features → Skills → 上传这个 zip。
3. 新建一个对话就可以用了，不需要特别的指令。

（用 Claude Code 的话：把 `skill/` 文件夹复制到 `~/.claude/skills/japanese-speaking-coach/`。）

## 2. 试用任务（请尽量都做）

### 任务一：回复建议（5 分钟）
把**你最近真实遇到过**、当时没听懂或不知道怎么回的 2–3 句日语粘贴进去（直接粘贴就行）。
- 例：店员说的话、同事/上司说的话、朋友发的 LINE。
- 如果对方是上司、老师、朋友，可以在前面加一句说明，比如「（对方是上司）」。

### 任务二：中文转日语（3 分钟）
输入 1–2 句「我想说……」，比如「我想说明天的聚会去不了，但不想得罪人」。

### 任务三：情景陪练（10 分钟）
输入「陪练」，从列表里选一个你**真的会遇到**的场景，走完一轮（大约 6–8 个来回）。
- 卡住时可以只回一个「？」，看看会给你什么帮助。
- 故意说错一两句也可以，看看提示是否有用。

### 任务四：复盘（2 分钟）
陪练结束后输入「复盘」，看看纠错和生词卡。

## 4. 给作者：如何整理反馈

- 每份反馈存为 `tests/feedback/<日期>_<昵称>.md`（昵称即可，不要写真名和联系方式）。
- 把第 1、4 题里的真实句子补进 `tests/sample_dialogues.md`（替换掉起草的测试句，第一阶段完成标准要求「真实对话」）。
- 第 3、4、9、10 题指出的问题，按 `docs/decisions.md` 的格式记录改动和理由。
