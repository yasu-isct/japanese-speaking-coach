# 2026-10-26：推荐更醒目，中文解释可以收起

这次完成了第一轮界面改动：推荐回复加粗并写明「⭐ 推荐」，中文意思与理由可以一键收起，警告始终保留，长中文会在窗口内换行。下面的结果来自固定合成文字和本机截图，**尚未证明真实课堂中更省力，也不代表所有显示条件都通过**。

## 改了什么

- 三条回复继续按丁寧／カジュアル／かんたん排列，不把推荐条目挪到首位。推荐使用同字号的粗体；其它回复的字号和颜色保持不变。
- 完整模式的工具栏新增「收起中文／展开中文」，同时控制三条中文意思与推荐理由。首次仍显示中文；一次运行内保留选择，切换模式或出现下一轮回复不会自动展开。没有写入用户设置文件。
- 「⚠ 对此对象不要用」独立显示，折叠中文时仍能看见。中文与警告按可用宽度换行，下一条回复从真实文本底边之后开始绘制。
- 保护拖动起点：没有先按下窗口正文时不执行拖动；按工具栏按钮会清除旧拖动起点，避免点击后移动鼠标触发异常或误拖。

实现位于 [overlay.py](../app/jsc_live/overlay.py)，无窗口测试位于 [test_overlay.py](../tests/test_overlay.py)。这一步没有改变请求内容、推荐选择或 API 调用次数。

## 相同输入下的改前／改后

工具：[capture_ui_iteration.py](../tools/capture_ui_iteration.py)。输入固定为三句公开／合成日语字幕、三种回复、一个推荐、一个警告，以及长中文、长理由和【出身地】占位。没有音频、网络请求、个人资料或私人存档。

| 对比度 | 颜色未改。在本轮不透明纯色背景上，按 sRGB 色值计算，推荐正文 16.94:1、其它回复 7.30:1、假名 13.14:1、中文 7.12:1、警告 7.98:1，激活按钮文字 6.57:1 | 这些是字心／背景的色值计算，不包含抗锯齿边缘；真实视频背景、默认 0.88 透明度和低透明度未重新截图验证，不能宣称全部通过 |

两倍字号测试发现窗口顶部离屏后，抓图工具记录原因并关闭窗口，没有裁掉问题区域冒充成功截图。后续应独立处理内容高度、滚动或布局选择；本轮不把这个失败藏进平均数字。
